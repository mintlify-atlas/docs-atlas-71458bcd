Work Time Recorder requires no sign-up, no installation, and no configuration. This guide walks you from a blank browser tab to a completed, saved work session in five steps. Everything after step two is optional — the core timer is ready the moment the page loads.

<Steps>
  <Step title="Open the App">
    You have two ways to open Work Time Recorder:

    **Option A — GitHub Pages (recommended)**

    Visit the hosted version directly in any modern browser:

    ```
    https://longlong007.github.io/work-time-recorder/
    ```

    No download needed. The Service Worker will cache the app on first load, so subsequent visits work offline.

    **Option B — Run locally from source**

    Clone or download the repository, then open `index.html` in your browser:

    ```bash
    # Clone the repo
    git clone https://github.com/longlong007/work-time-recorder.git
    cd work-time-recorder

    # Open directly (timers and history work, but Service Worker / PWA is disabled on file://)
    open index.html
    ```

    <Note>
      If you want the Service Worker and PWA install prompt to work locally, serve the files over HTTP instead of opening `index.html` directly as a `file://` URL:

      ```bash
      python3 -m http.server 8080
      ```

      Then navigate to `http://localhost:8080` in your browser.
    </Note>
  </Step>

  <Step title="Record Your First Session">
    Once the app is open, you will see the main timer panel on the left and the history panel on the right.

    1. **Name your session** (optional) — type a brief description in the **工作名称** (Work Name) input field, for example `Write documentation`. You can also click a quick-select tag (such as **开发** or **学习**) to pre-fill the name, or use the **▾** dropdown to pick from today's to-do list.
    2. **Start the timer** — click the **▶ 开始 (Start)** button. The status indicator turns green and the elapsed counter begins counting up from `00:00:00`.
    3. **Work** — the timer runs in the background even if you switch tabs. The current session is persisted to `localStorage` immediately, so a browser refresh or accidental close will not lose your start time.
    4. **Stop the timer** — when you finish, click **⏸ 结束 (Stop)**. The session is saved instantly and appears at the top of the history list on the right panel.

    Your first record is now saved. It shows the date, start time, end time, elapsed duration, and work name. You can edit any field with the ✏️ pencil icon or delete the record with 🗑️.
  </Step>

  <Step title="View Your Statistics">
    Click the **统计 (Stats)** tab at the top of the right panel to open the statistics view.

    The summary section displays three time ranges side by side:

    | Range | What it shows |
    |---|---|
    | **今日 (Today)** | Total tracked time for the current calendar day |
    | **本周 (This Week)** | Total from Monday of the current week through today |
    | **本月 (This Month)** | Total from the 1st of the current month through today |

    Each range has three filter modes you can toggle:

    - **Work** — counts all sessions that do not carry the **休息 (Rest)** tag
    - **Rest** — counts only sessions tagged as rest
    - **All** — counts every session regardless of tag

    Statistics update automatically each time you stop a session.
  </Step>

  <Step title="Install as a PWA (Optional)">
    Work Time Recorder is a Progressive Web App, so you can pin it to your desktop or home screen for instant, full-screen access — no browser chrome required.

    **Desktop (Chrome or Edge)**

    Look for the install icon (⊕) in the right side of the address bar. Click it and then click **Install** in the confirmation dialog. The app opens in its own window and behaves like a native application.

    **Mobile (iOS Safari or Android Chrome)**

    1. Open the app in your mobile browser.
    2. Tap the browser's **Share** menu (iOS) or the three-dot **Menu** (Android).
    3. Select **Add to Home Screen**.
    4. Confirm the name and tap **Add**.

    After installation, the app launches directly from your home screen and works fully offline thanks to the cached Service Worker.
  </Step>

  <Step title="Enable Cloud Sync (Optional)">
    By default all data stays local. If you want your records, todos, tags, and settings to sync across multiple devices, you can connect a CloudBase account.

    See the [Cloud Sync overview](/cloud/overview) for account setup instructions, migration options, and conflict-resolution behaviour.
  </Step>
</Steps>

<Tip>
  Press the **Space** key anywhere on the page (when your cursor is not inside a text input) to instantly start or stop the timer — no mouse required. Use `Ctrl + E` (or `Cmd + E` on Mac) to export your records as a CSV at any time, and `Ctrl + /` to open the full keyboard shortcuts reference.
</Tip>
